# Seene Product

Seene turns a developer's existing application components into cinematic 3D motion through a human-first scene studio. Developers work in source, keep their existing providers/data/styles, and refine scenes live in the browser using the interactive Scene Inspector. There is no AI subscription, prompt generation, or cloud server requirement.

## Browser experience

The product uses a minimal preview shell: black scene space, generous padding, plain rounded controls over a progressive bottom blur. Play/pause, replay, a timeline, the Scene Inspector, and export are the core controls.

## Visual language

Default compositions use deliberate close oblique camera framing, surface-aligned camera travel, meaningful foreground/background depth and smooth, slow motion. Focus follows camera-axis depth through distance and aperture.

## Export

Local MP4 export at 30/60/120 FPS is delivered through the CLI and live capture clock. FFmpeg and Chromium are local prerequisites.
